# Copy LP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship lpagent-style Copy LP: follower starts a session on a leader `G…` with a coefficient; Aquarius LP actions after `cursor_ts` become scaled CopyOps in a live queue; Generate draft prefills Strategies (no custodial auto-exec).

**Architecture:** Enrich liquidity events with `derived.actor` (claim from topics; deposit/withdraw via tx source lookup). Persist `copy_sessions` / `copy_ops` in the indexer SQLite (read/write from api-server). Reconcile ops on session poll. Web `/copy` UI + Header nav + Strategies draft bridge.

**Tech Stack:** Rust (`pool-indexer`, `api-server`, `dex` RPC), SQLite (`INDEXER_DB_PATH`), Next.js (`apps/web`), localStorage Strategies.

**Spec:** `docs/superpowers/specs/2026-08-05-copy-lp-design.md`

## Critical discovery (do not skip)

Live Aquarius events:

| kind | topics | actor location |
|------|--------|----------------|
| `trade` | symbol, token_in, token_out, **G user** | topic[3] |
| `claim_fees` | symbol, **G user**, … | topic[1] |
| `deposit_liquidity` | symbol, **C token**, **C token** | **no G in topics** |
| `withdraw_liquidity` | symbol, **C token**, **C token** | **no G in topics** |

Therefore Task 1 must resolve deposit/withdraw `actor` from **`tx_hash` → transaction source account** (RPC `getTransaction` / Horizon), not from topics alone.

```rust
/// Extract the Stellar account (`G…`) that submitted the tx from a
/// `getTransaction` JSON-RPC result (or Horizon-compatible envelope summary).
pub fn source_account_from_get_transaction(result: &serde_json::Value) -> Option<String> {
    // Prefer decoded / envelopeSource / account fields commonly returned by
    // stellar-rpc getTransaction. Fall back to parsing envelopeXdr only if needed.
    result
        .pointer("/account")
        .and_then(|v| v.as_str())
        .map(str::to_owned)
        .or_else(|| {
            result
                .get("envelopeJson")
                .and_then(|e| e.pointer("/tx/sourceAccount"))
                .and_then(|v| v.as_str())
                .map(str::to_owned)
        })
}
```
